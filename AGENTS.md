# MeteoTrace instructions

- Основная спецификация проекта находится в METEOTRACE_SPEC.md.
- Перед изменениями обязательно прочитай её полностью.
- Работай только с существующим проектом.
- Не создавай DEMO под видом LIVE.
- Не используй нелегальный scraping, скрытые API и обход авторизации.
- Сохраняй существующую архитектуру и стиль кода.
- После каждого этапа запускай lint, typecheck и build.
- Не переходи к дополнительным источникам, пока EUMETSAT и RainViewer не работают.
- Фиксируй прогресс в IMPLEMENTATION_STATUS.md.
